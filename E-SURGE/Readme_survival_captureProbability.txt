The .csv file contains the capture-mark-recapture dataset. The .xls file is the output from the discussed model of adult survival and capture probability fit using E-Surge for the population of Triturus ivanbureschi. Several sheets are important: "Model definition" contains the matrices and the corresponding phrases used in the GEMACO interface of the software; "Deviance" provides the QAIC, deviance, etc.; "Reduced set of parameters" gives the parameter estimates - the variables' number codes are defined in parentheses at first mention.
